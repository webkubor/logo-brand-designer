为新产品做 Logo、重设计旧标识，或适配插件图标。用 Codex 或 Claude Code 比较候选、收集反馈，交付透明底 SVG。

安装技能

在终端运行命令，然后在项目里告诉 AI 助手你想设计什么。

npx skills add webkubor/logo-brand-designer

比如：用 logo-brand-designer 给这个项目设计 Logo，先给我几种黑白轮廓供选择。

查看安装说明

从黑白稿到可用的标识

  1. 选形

    比较黑白轮廓，记录保留和淘汰的理由。

  2. 定色

    保持轮廓，比较深浅背景下的配色。

  3. 评审

    选候选，也可以写建议，意见保存在本地工作台。

  4. 交付

    检查小尺寸和透明度，交付 SVG、颜色规范与评审页。
