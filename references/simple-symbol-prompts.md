# 简洁符号探索与锁形配色

当用户要求简洁、个性、记得住，或反对把多个概念复杂整合时读本页。若用户明确要求复杂纹章、具象插画或既有品牌延展，按其方向处理，不套用本页的探索限制。

## 先探索一个完整符号

先把产品背景压成一个整体气质，再给模型视觉约束。产品资料用于判断方向，不应自动变成必须画进去的对象清单。反复强调「只属于本产品的事实」容易诱导模型把账号、沙箱、协议、人物和交接物拼成说明图。

可调整的出图提示骨架：

> 设计一张只有编号的黑白品牌符号探索板，候选之间有明确的整体形态差异。标志首先是一块完整、紧凑、自然的剪影；用一个具体的轮廓或留白特征形成记忆点，不图解技术功能。优先整体比例与大开口，减少尖细末端和微小细节。初轮可尝试最多两块粗实形体、一个主要负空间，作为减法起点，不强制把所有方案做成同一种结构。浅底黑标、深底反白以及小尺寸采用同一几何母版。不要名称、字母绑定、理念标签、节点箭头拼装、通用平台图标或现有商标变体。平面单色，无质感、光影或三维包装。

名称未确认时，避免用造词、字母或复杂词根牵引图形。参考成熟品牌时提取简洁程度、整体性和识别方式，不复制其符号。

盲测先问第一眼像什么、能记住哪一处、缩小是否清楚，再给产品背景判断气质。审阅不能为了证明产品专属性而重新要求用户反对的功能图解。与品牌建立联系可以是气质与整体识别，不必是多层寓意。

## 用户选形后只变配色

1. 保存用户明确指向的原始图、版本或截图；若原始生成图与后画 SVG 不同，以用户实际选定的那一份为准，不能默认认可后者。
2. 保持外轮廓、比例、开口、收尖和留白，仅比较色彩。先区分「选色系」和「选表达」：纯色、渐变、通透叠色按用户要求探索。单色形态检验不等于最终只能纯色，锁形也不等于只允许油漆桶填充。每组在相同尺寸、相同浅底与深底上展示；不借配色擅改几何。
3. 色彩是本次建议还是已批准 token 要分开。生成图中的 hex 标签不是像素证明；定稿时用 SVG/渲染读回核对精确颜色。
4. 形态认可不等于名称、字标、颜色或品牌整体定稿。已经选定的形态进入配色评审后，不再次要求视觉模型自由发散重设计。

锁形配色提示骨架：

> 编辑已附的用户选定母版，仅改变色彩表达。严格保留外轮廓、比例、主要开口、端点与留白；不要重画、几何化、改成字母或补细节。按用户选定的色系与表达方式，比较纯色、渐变或通透层次；未要求的立体挤出、投影与额外意象不加。每组使用同一形态与光学尺寸，在相同浅底、深底和小尺寸中比较。色系认可与具体色彩效果定稿分别记录，建议色值与实测颜色分开。

矢量化是另外一项几何工作：保留原母版并对照渲染后轮廓；若工具只得到了近似形状，要明确标注差异，不能用「优化」替换用户已选的形态。
