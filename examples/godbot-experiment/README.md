# Godbot 标识设计实验

本目录是 `logo-brand-designer` 技能的一次测试案例，目标项目为 [renjiegod/dsh-godbot](https://github.com/renjiegod/dsh-godbot)，与 NativeCrew 无关。

## 设计约束

- 不做吉祥物。
- 不复用 Godbot 现有标识中的元素。
- 配色探索限定在蓝色到紫色之间。
- 产品背景：多 Agent 协作工作台，支持派工、结果复核和原生会话接管。

## 当前进度

第一轮黑白生成稿已淘汰：三个形态分别容易被看成箭头、字母和通用链环。第二轮从抽象形态重新探索，再为三款候选分别加入蓝紫配色。初评与独立盲评对 01/02 的优先级有分歧：01 缩小后更稳，但可能像云形/山形；02 更有记忆点，但可能像 A/K 字母或分流路径；03 偏通用同步图标，建议淘汰。三款都尚未通过定稿门槛。完整评审见 [`process/visual-review.md`](process/visual-review.md)。

下一轮先围绕 02 去字母化，并保留 01 备选；在作者确认前，PNG 仅作探索参考，不是最终标识。`experiment.json` 中的 hex 是生成提示目标，不是实测色值或已批准的颜色 token。尚未选定形态，因此没有正式 SVG、作者签字或产品接入。

## 页面分工

官网与评审页可以并存：官网介绍产品定位与品牌故事；私有评审页展示候选、记录作者反馈和确认决策。本案例只提供本地评审页，不生成或发布公开官网。

## 评审

本地打开 [`index.html`](index.html) 可比较三款形态和配色，并填写给作者的建议。建议保存在当前浏览器，可复制后发给作者；页面不会自动上传。真实页面截图见 `screenshots/review.png`。

实时评审工作台的“补充建议”也支持直接输入，并写入本地进度状态文件。`screenshots/workbench-note-input-test.png` 是通用工作台的界面验证截图，其中示例文字仅用于验证，不代表作者意见；本轮 Godbot 候选仍在独立评审页。
